# big-vibecode

Five game/tool projects, each built by a Fable 5 session driven by that folder's `prompt.md`.
Each folder also has a `CONTEXT.md` (domain glossary + decisions) that the prompt inlines.

## Build order (suggested)
1. **flappy-bird** — warm-up, smallest scope
2. **baccarat-sdl** — logic-heavy but small UI
3. **roulette-3d** — Godot + 3D physics
4. **mc-randomizer** — scripting/API-driven, no engine code
5. **geometry-dash** — largest: engine + gamemodes + 10 levels + audio

## Assets policy (all projects)
CC0/public-domain preferred; CC-BY acceptable with attribution; no NC-only licenses; every asset logged in the project's `LICENSES.md`; nothing ripped from the original games.
